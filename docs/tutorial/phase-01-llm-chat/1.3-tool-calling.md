## 2. 背景与概念

待写。（要点：Agent 循环的一步（step）是一次 LLM 调用加它的工具执行；每一步开始前检查所在车道的收件箱，把这一轮进行中收到的新消息（steering）按顺序加进当前对话历史，并在上下文里标明“这是任务进行中收到的新消息”，下一步一起发给 LLM；工具正在执行时不打断，新消息等这一步结束；新消息排在这一步的工具结果之后，保持工具调用与结果相邻；循环要能响应“停”，取消沿用事件循环的取消机制；每一轮对话有总的截止时间，超时后停下并回报；消息用内容块表示（见 1.2）；多步工具调用里把推理块原样回传给模型；Agent 事件：循环不直接打印，而是向外发统一的事件（文本增量、工具开始、工具结束、产物、错误、结束），命令行前端订阅并打印；以后 Discord 前端（1.7）、流式输出（支线 llm-1.4）、轨迹（2.6）都订阅同一份事件，不在循环里另写一套；本章的工具先用一张最简单的表，1.4 换成工具运行时；测试：用假 Transport 按脚本依次返回“调用工具 A、再调用工具 B、最后回答”，在录制回放（支线 llm-1.7）之前就能测循环的逻辑。）
