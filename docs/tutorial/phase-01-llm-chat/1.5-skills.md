- [llm-4.6 热重载与版本](../../contrib/quest-llm-04-skills-advanced/llm-4.6-skill-hot-reload.md)（支线 llm-04：Skills 进阶）：监视 Skill 目录的变化并重新装载，会话进行中的 Skill 如何平滑切换；Skill 之间的依赖与冲突检测
